## Coding Values

- Prefer simple, explicit code over clever code.
- Prefer deterministic behavior over hidden behavior.
- Keep responsibilities small and focused.
- Keep dependencies explicit.
- Use abstractions only when they create a clear boundary.
- Prefer strong types over loosely typed data.
- Keep important checks and rules visible in the code.
- Query and process only the data that is needed.
- Optimize for maintainability, not minimum line count.
- Follow project conventions unless there is a clear reason to improve them.
